## Test-mode contract

The default is false. A disposable QA build may set `EXPO_PUBLIC_RELIEF_TEST_MODE=true`. The flag does not supply credentials, bypass Supabase authorization, create users, write production data, upload files, or complete purchases. Simulated and unavailable operations are labelled in Feature Lab or on the destination screen.
