# Motorway-service-area toilet feasibility — R5A

National Highways publishes accessible-service guidance and points users to detailed access guides. General motorway-service requirements also describe toilets and disabled access. That is useful policy/context evidence, but it is not an open, facility-level source that can safely supply a Relief point.

The bounded pass found no current reusable structured feed containing stable service-area identifiers, coordinates, status and direct toilet/accessibility fields. AccessAble is the detailed guide route but is permission-gated for reuse. The previously identified non-exhaustive dataset was not used.

Results:

- lawful direct-toilet records: **0**;
- ready net-new cohort: **0**;
- overlap with Relief: not measured because the source contract failed first;
- recommendation: **PERMISSION_REQUIRED**.

The appropriate next step is a targeted data-partnership request to National Highways or service-area operators, not scraping or an inference that every road-service point is a canonical public toilet.
